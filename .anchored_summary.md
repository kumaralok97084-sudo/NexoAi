### Key Decisions
- **`@bot.tree.error` over `@bot.event`**: discord.py 2.7.1 doesn't dispatch `app_command_error` event
- **`UnlimitedTree` subclass**: skips discord.py's 100-command client-side check (Discord API still enforces 100 global)
- **Global sync over per-guild**: both are limited to 100, global is simpler
- **Generated emojis over scraped ones**: emoji.gg/discadia block automated requests (Cloudflare); generating with Pillow gives custom consistent NQN-style designs with no copyright issues
- **81 emoji files → 81 Application Emojis**: upload script handles rate limits with sequential deletes (0.5s apart) and sequential uploads (every 5th)
